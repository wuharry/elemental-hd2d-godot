# 玩法規則（來源：Harvey 的規則整理，2026-11-17）

一句話：手機上的元素組招動作冒險。玩家自己選普通組合或元素融合，搭配環境反應、高友軍傷害與多人救助。

狀態只有三種：**已定**（照做）、**草案**（Gemini 的建議，Harvey 還沒拍板，程式標 `DRAFT`）、**待定**（沒有方案，不要自己決定）。

## 1. 定位與畫面

| 項目 | 設定 | 狀態 |
| --- | --- | --- |
| 平台 | 手機，橫向 | 已定 |
| 視角 | 斜俯視，即時移動與戰鬥 | 已定 |
| 美術 | 像素角色 + 細緻 3D 場景、材質、光影、景深（HD-2D） | 已定，做法見 BLUEPRINT |
| 模式 | 單人冒險、多人合作 | 已定；多人上限待定 |
| 核心樂趣 | 臨場組招、主動融合、元素互動、走位、隊友互坑 | 已定 |

## 2. 元素與四格佇列

- 玩家配置四種元素出戰，對應右搖桿外圍四顆元素鍵。**已定**
- 點元素鍵把該元素加入佇列；同一種可以重複加（雷＋雷）。**已定**
- 佇列最多四格，限制的是「目前占用幾格」，不是「最多按四次」；融合後騰出的格子可以再加。**已定**
- 不必填滿四格就能施法。**草案**
- 四個元素鍵以圖示辨識。每個待發元素在角色身邊顯示一顆對應的小光點，重複元素各占一顆；融合後顯示融合元素的光點，施放後消失。角色頭頂與 HUD 均不顯示累積槽。**已定**
- 元素總共幾種、怎麼取得。**待定**

## 3. 普通組招與主動融合

兩條路線必須同時存在：

| 路線 | 佇列 | 結果 |
| --- | --- | --- |
| 普通組招 | `[水][火][雷][雷]` | 保留四顆，形成這組配方的法術 |
| 主動融合 | `[蒸][雷][雷][空]` | 水＋火融合成蒸氣只占一格，多出一個空位 |
| 融合後補入 | `[蒸][雷][雷][冰]` | 補上第四顆，形成另一組配方 |

- 水＋火**不會**自動融合，玩家要能保留普通組合。**已定**
- 普通組招不是把四顆元素逐一射出去，而是生成一個完整的組合法術。**已定**
- 融合要改變法術的用途與特性；如果融合永遠比較強，普通組招就沒意義。**已定**（設計原則）
- 融合用獨立按鍵，不占用長按。**已定**
- 融合取哪兩格：固定最後兩格。**草案**（代價：`[水][火][雷][雷]` 排好後不能回頭融合前面的水火）
- 複合元素不可再融合。**草案**
- 普通組招不看順序、只看數量比例。**草案**
- 各配方產生什麼法術。**待定**

## 4. 操作與護盾

| 操作 | 功能 | 狀態 |
| --- | --- | --- |
| 左搖桿 | 移動 | 已定 |
| 右搖桿 | 瞄準與施放 | 已定 |
| 輕點元素鍵 | 加入該元素 | 已定 |
| 長按元素鍵 | 開對應屬性的護盾 | 已定 |
| 融合鍵 | 執行融合 | 已定；選格方式見第 3 節 |
| 右搖桿上方三顆 | 快捷法術 | 已定 |

- 長按已經給護盾，不能再讓長按負責融合（防禦時會誤改配方）。**已定**
- 開盾保留已排好的佇列；護盾用貼身外殼、腳下標記呈現，與待發元素區分。**草案**
- 護盾是長按觸發後持續固定秒數（或吸收一定傷害後破裂），開盾期間可以組招與攻擊。**草案**
- 護盾耗能。**待定**

## 5. 右搖桿施法

| 狀態 | 行為 | 狀態 |
| --- | --- | --- |
| 推入內圈 | 只調整方向，不開火 | 草案 |
| 推入外圈（持續型） | 開始噴射／引導，放開結束 | 草案 |
| 推入外圈（蓄力或拋投型） | 開始蓄力或調整落點，放開時發射 | 草案 |
| 沒施放就取消瞄準 | 保留佇列 | 草案 |
| 完成一次施法 | 清空這次用掉的佇列 | 草案 |

- 內外圈比例要實機測，之前提過的百分比不算數。**待定**（程式暫用 0.55）
- 取消方式：推到外圈後拉回內圈再放開。**草案**
- 副手武器：輕點右搖桿中心，不消耗佇列。**草案**（原方案「空佇列才能用副手」有矛盾，已建議廢除）

## 6. 法術記憶與快捷

- 用某個法術累積擊殺一定數量後，解鎖它的快捷施放。**已定**
- 戰鬥介面有三個快捷槽，位置在右搖桿上方；快捷與手動佇列是兩套資訊。**已定**
- 點快捷後用右搖桿瞄準施放。**草案**
- 手動佇列已有元素時點快捷：原佇列暫存，放完快捷後恢復。**草案**
- 要裝著對應元素才能裝備該快捷；支援型法術改計吸收傷害量／治療量／助攻數。**草案**
- 擊殺門檻、CD、耗魔。**待定**

## 7. 元素互動、友傷、復活

- 元素互動發生在配方裡，也發生在命中之後；對象包含敵人、隊友、角色狀態、地面、場景物件。**已定**
- 方向：水→潮濕→雷導電；水面結冰改變通行；火點燃物件、水滅火；法術推動或破壞物件，利用懸崖與障礙。**已定**（傷害、範圍、持續時間待定）
- 高友軍傷害是核心要求。**已定**；比例：直接法術 50%、環境反應 100%。**草案**
- 單人可以看廣告復活一次；按每關或每趟重置。**待定**
- 多人：存活隊友可以不限次數救助倒地隊友，但不是瞬間救起，團滅也不會自動復活。**已定**
- 靠近倒地隊友自動讀條救助，可邊移動邊救，出圈中斷；團滅消耗全隊共用次數重開當前遭遇。**草案**

## 8. 關卡、難度、成長

- 場景兩類：開闊探索區（森林、雪原、橋、大廳、河流、懸崖）與洞窟／地下城副本。**已定**
- 要避免的四件事：**已定**
  1. 生怪組合讓人沒有應對方法（免疫怪 + 追擊怪 + 地形危險疊在一起）。
  2. 只靠怪物血量與傷害暴增來提高難度。
  3. 重複清怪、沒有變化的冗長流程。
  4. 元素選擇、配方、走位、地形利用失去作用。
- 不是禁止數值成長，而是不能最後只剩刷攻擊力才能過關。**已定**
- 裝備強化幅度、詞條、角色等級。**待定**

## 9. 一趟的流程

出發準備（配四種元素與三個已解鎖快捷）→ 進入冒險（單人或多人，探索區或副本）→ 觀察遭遇（敵人、隊友、可利用地形）→ 組招與交戰 → 完成關卡目標 → 記錄成長並重新配裝。**已定**（任務類型、獎勵、失敗保留多少進度待定）
