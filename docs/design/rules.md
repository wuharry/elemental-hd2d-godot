# 玩法規則（來源：Harvey 的規則整理，2026-11-17）

一句話：手機上的元素組招動作冒險。玩家自己選普通組合或元素融合，搭配環境反應、高友軍傷害與多人救助。

狀態只有三種：**已定**（照做）、**草案**（Gemini 的建議，Harvey 還沒拍板，程式標 `DRAFT`）、**待定**（沒有方案，不要自己決定）。

## 1. 定位與畫面

| 項目 | 設定 | 狀態 |
| --- | --- | --- |
| 平台 | 手機，橫向 | 已定 |
| 視角 | 斜俯視，即時移動與戰鬥 | 已定 |
| 美術 | 像素角色 + 細緻 3D 場景、材質、光影、景深（HD-2D） | 已定，做法見 BLUEPRINT |
| 模式 | 單人冒險、多人合作 | 已定；多人上限待定 |
| 核心樂趣 | 臨場組招、主動融合、元素互動、走位、隊友互坑 | 已定 |

## 2. 元素與四格佇列

- 玩家從**水、土、冰、雷、火、秘法（奧術）、生命**七種基礎元素中選四種出戰，對應右搖桿外圍四顆元素鍵。七種都有獨立圖示。**已定**
- 基礎元素直接採用「冰」（不另拆「寒」），每種基礎元素都能獨立作為主力技能使用。**已定**
- 玩家沿村莊道路可以走到村口外、地圖邊緣的傳送門。傳送門通往七座相連的元素祭壇。靠近對應祭壇時，點選亮起的出戰格，即可把該格替換成祭壇元素。**已定**
- 點元素鍵把該元素加入佇列；同一種可以重複加（雷＋雷）。**已定**
- 佇列最多四格，限制的是「目前占用幾格」，不是「最多按四次」；融合後騰出的格子可以再加。**已定**
- 不必填滿四格就能施法。**草案**
- 四個元素鍵以圖示辨識。每個待發元素在角色身邊顯示一顆對應的小光點，重複元素各占一顆；融合後顯示融合元素的光點，施放後消失。角色頭頂與 HUD 均不顯示累積槽。**已定**
- 元素如何解鎖取得。**待定**（目前原型提供基礎元素供配裝測試）

## 3. 普通組招與主動融合

兩條路線必須同時存在：

| 路線 | 佇列 | 結果 |
| --- | --- | --- |
| 普通組招 | `[水][火][雷][雷]` | 保留四顆，形成這組配方的法術 |
| 主動融合 | `[蒸][雷][雷][空]` | 水＋火融合成蒸汽只占一格，多出一個空位 |
| 融合後補入 | `[蒸][雷][雷][冰]` | 補上第四顆，形成另一組配方 |

- 水＋火**不會**自動融合，玩家要能保留普通組合。**已定**
- 普通組招不是把四顆元素逐一射出去，而是生成一個完整的組合法術。**已定**
- 普通組招**不看順序**、只看元素成分與數量比例；當佇列含融合元素時，由融合元素主導法術型態（例如含「霧」走幻覺／感知控場系）。**已定**
- 融合要產生**質變的新元素**並改變法術用途與特性；如果融合永遠比較強，普通組招就沒意義。**已定**（設計原則）
- 融合用兩節鎖鏈相扣的圖示，輕點獨立按鍵執行。**已定**
- **相剋規則**：相剋組合（**土↔雷、水↔雷、火↔冰、生命↔秘法**）在佇列內**可並存（不互銷按鍵）**，但**無法按鎖鏈主動融合**。**已定**
- 融合取哪兩格：固定最後兩格。**草案**（代價：`[水][火][雷][雷]` 排好後不能回頭融合前面的水火）
- 複合元素不可再融合（只融一次）。**草案**

## 4. 操作與護盾

| 操作 | 功能 | 狀態 |
| --- | --- | --- |
| 左搖桿 | 移動 | 已定 |
| 右搖桿 | 瞄準與施放 | 已定 |
| 輕點元素鍵 | 加入該元素 | 已定 |
| 長按元素鍵 | 開對應屬性的護盾（防禦相應元素並解除特定狀態） | 已定 |
| 融合鍵 | 執行融合 | 已定；選格方式見第 3 節 |
| 右搖桿上方三顆 | 快捷法術 | 已定 |

- 長按已經給護盾，不能再讓長按負責融合（防禦時會誤改配方）。**已定**
- **護盾觸發時長**：手機優先長按觸發；電腦端預設長按 **1.5 秒**觸發，設定頁可自訂 **1–3 秒**。**已定**
- 開盾保留已排好的佇列；護盾用貼身外殼、腳下標記呈現，與待發元素區分。**草案**
- 護盾達到長按門檻即啟動，之後持續固定時間；手指可以放開並繼續組招與攻擊，不需要持續按住。**已定（2026-11-26）**
- 固定持續秒數、數值與各盾解狀態對照仍是可調原型；一般護盾不以吸收傷害破裂為前提，唯**土盾（石甲）**定案為雙條件（先到為準）：固定持續時間與護盾血量並存，血量歸零即提前碎甲（移速 `-50%`、物傷減免 `80%`），且**不可回復護盾血量、只能重新召喚**。
- 護盾耗能。**待定**

## 5. 右搖桿施法

| 狀態 | 行為 | 狀態 |
| --- | --- | --- |
| 推入內圈 | 只調整方向，不開火 | 草案 |
| 推入外圈（持續型） | 開始噴射／引導，放開結束 | 草案 |
| 推入外圈（蓄力或拋投型） | 開始蓄力或調整落點，放開時發射 | 草案 |
| 沒施放就取消瞄準 | 保留佇列 | 草案 |
| 完成一次施法 | 清空這次用掉的佇列 | 草案 |

- 內外圈比例要實機測，之前提過的百分比不算數。**待定**（程式暫用 0.55）
- 取消方式：推到外圈後拉回內圈再放開。**草案**
- 副手武器：輕點右搖桿中心，不消耗佇列。**草案**（原方案「空佇列才能用副手」有矛盾，已建議廢除）

## 6. 法術記憶與快捷

- 用某個法術累積擊殺一定數量後，解鎖它的快捷施放。**已定**
- 戰鬥介面有三個快捷槽，位置在右搖桿上方；快捷與手動佇列是兩套資訊。**已定**
- 點快捷後用右搖桿瞄準施放。**草案**
- 手動佇列已有元素時點快捷：原佇列暫存，放完快捷後恢復。**草案**
- 要裝著對應元素才能裝備該快捷；支援型法術改計吸收傷害量／治療量／助攻數。**草案**
- 擊殺門檻、CD、耗魔。**待定**

### 三種法術層級與工坊綁定（2026-11-26，Harvey 確認）

1. **普通組合技**：1–4 顆基礎元素，不按融合鍵，成分與數量決定法術，不看順序。
2. **主動融合與融合組招**：按鎖鏈把兩個基礎元素融合成一個新元素，占一格；可直接施放，或加入其他基礎／融合元素組招。新元素的身分保留，不能在配方解析時攤回原料。
3. **具名秘術**：探索法術書解鎖，使用含融合元素的特定配方。第一個實戰原型是 `[霧][水][水]` 的「降雨」。其他具名法術的最終配方、格數與效果尚未實作／定案，例子不等於完整內容表。

- 學會秘術時，相同手動配方預設透過右搖桿直接施放該秘術。
- **魔術師工坊分開設定手動配方與快捷法術**。手動配方可選普通組合或任一符合配方、已解鎖的具名秘術；快捷槽另外綁定法術身分，不因手動設定變動而改變。
- 可以手動 `[霧][水][水]` 放普通霧水法術，快捷放降雨；也可同配方手動放具名 A、快捷放具名 B，前提是 A、B 都已解鎖，且快捷符合熟練條件。裝上快捷不自動改寫手動綁定。
- 法術書解鎖與快捷熟練是兩個條件。第一輪訓練以 **3 次有效生效** 模擬快捷熟練，僅為可測原型，不能覆蓋上方正式擊殺／支援成長的待定門檻。
- 教學順序：單元素 → 普通組合 → 初次快捷 → 主動融合 → 融合組招與環境連鎖 → 具名秘術。快捷是每招的操作熟練，後續層級同樣可以使用。

## 7. 元素互動、友傷、復活

- 元素互動發生在配方裡，也發生在命中之後；對象包含敵人、隊友、角色狀態、地面、場景物件。**已定**
- 方向：水→潮濕→雷導電；水面結冰改變通行；火點燃物件、水滅火；法術推動或破壞物件，利用懸崖與障礙。**已定**（傷害、範圍、持續時間待定）
- 高友軍傷害是核心要求。**已定**；比例：直接法術 50%、環境反應 100%。**草案**
- 單人可以看廣告復活一次；按每關或每趟重置。**待定**
- 多人：存活隊友可以不限次數救助倒地隊友，但不是瞬間救起，團滅也不會自動復活。**已定**
- 靠近倒地隊友自動讀條救助，可邊移動邊救，出圈中斷；團滅消耗全隊共用次數重開當前遭遇。**草案**

## 8. 關卡、難度、成長

- 場景兩類：開闊探索區（森林、雪原、橋、大廳、河流、懸崖）與洞窟／地下城副本。**已定**
- 要避免的四件事：**已定**
  1. 生怪組合讓人沒有應對方法（免疫怪 + 追擊怪 + 地形危險疊在一起）。
  2. 只靠怪物血量與傷害暴增來提高難度。
  3. 重複清怪、沒有變化的冗長流程。
  4. 元素選擇、配方、走位、地形利用失去作用。
- 不是禁止數值成長，而是不能最後只剩刷攻擊力才能過關。**已定**
- 裝備強化幅度、詞條、角色等級。**待定**

## 9. 一趟的流程

出發準備（配四種元素與三個已解鎖快捷）→ 進入冒險（單人或多人，探索區或副本）→ 觀察遭遇（敵人、隊友、可利用地形）→ 組招與交戰 → 完成關卡目標 → 記錄成長並重新配裝。**已定**（任務類型、獎勵、失敗保留多少進度待定）
