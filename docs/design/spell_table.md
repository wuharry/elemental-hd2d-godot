# 法術組合與呈現效果填寫表

依據 [rules.md](rules.md) 的 7 種基礎元素（`水、冰、土、雷、火、秘法、生命`）與 4 格佇列規則整理。  
**填寫說明**：先填「施放型態」與「呈現效果與機制」，最後一欄「名稱」可留空等填完或實作一輪後再補（命名規範與 Prompt 見文末第七節）。  
同元素重複（如 `火火`、`火火火`）預設視為該配方的強化／放大版，不另占新列。

## 七、法術命名風格與 AI 命名 Prompt

### 命名風格原則（原創融合版）

1. **節奏簡短、看名知意**：中文以 `2–4` 字為主（具名秘術最多 `5` 字），一眼看得出「屬性＋施放型態或物理現象」，不寫冗長中二句。
2. **Magicka 元素直覺感**：偏重真實物理現象、施法型態與高友傷法師氛圍（如 `射線、噴流、地裂、彈幕、風暴、凝結、引爆`），偶爾保留一點法術失控或奇幻術士感。
3. **Warframe Mod 模組術語感**：高階組合、融合質變與變體法術引入冷冽精準的物理／能量詞彙（如 `過載、裂隙、極化、湧流、折射、脈衝、失溫、高壓、電離、連鎖、相變`），讓「普通組招」與「融合／秘術」在命名層級上有明顯區隔。
4. **層級區分**：
   - **普通組合（二～四元素）**：`[屬性／現象] + [形態]`，直白好記（例：`泥漿噴流`、`高壓水束`、`靜電水球`）。
   - **融合元素單放**：突出質變後的物質特性（例：`高壓蒸流`、`迷障水霧`、`纏生荊蔓`、`腐蝕毒彈`）。
   - **具名秘術**：更有儀式感或氣候／戰場級現象感，可用 Mod 風格複合詞或經典法術名（例：`驟雨召喚`、`過載磁暴`、`失溫領域`）。
5. **避開侵權紅線**：**禁止**照抄《絕望地下城》等既有遊戲的原創特有名稱與整套「三元素配方→法術名」對照（如「鑽石鳳凰」「鑽石裂鳥」「麋鹿炸彈」「禮物飛彈」「漸凍光線／漸凍激光」「毒候鳥」等）；通用自然詞（如落雷、暴風雪、地震）可用，但整表需依本作的實際施放型態與機制重新命名。
