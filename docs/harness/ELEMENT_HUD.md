# 元素 HUD 與祭壇操作

Harvey 於 2026-11-21 指定：遊戲操作盡可能用圖示與畫面傳遞訊息。改動 HUD、傳送門、祭壇或配裝畫面時，以這份規格與 `docs/design/rules.md` 核對。

| 玩家要做的事 | 畫面與操作 |
| --- | --- |
| 融合已排入的元素 | 獨立按鈕畫**兩節互相扣住的鎖鏈**。兩個鏈環都要看得出中空和交扣位置。可融合時提亮，輕點一次嘗試融合。用同一輪廓表達兩種狀態，避免和鎖住快捷槽的掛鎖混淆。 |
| 組招、瞄準 | 左拇指移動，右拇指輕點已裝備的元素圖示，再用右搖桿瞄準施放。讓玩家能持續走位，同時用另一指操作。 |
| 前往祭壇 | 傳送門設在西村口外、可行走地圖的邊緣。玩家從出生點沿石板路穿過最後一排房舍，就能走到門前。靠近時顯示進門圖示，點一下或按 E 抵達森林的元素祭壇。從回程門返回時，角色站在西村口的門前，面向村內的道路保持暢通。 |
| 裝備元素 | 六座元素祭壇緊連在共用石座上，各有與 HUD 相同的元素圖示。靠近最近的一座時，右側顯示該元素並亮起可替換的出戰格。點一格立即替換，鍵盤 1–4 對應同一組位置。已裝備時只標亮該格，並顯示「已裝備」。搖桿維持可用，離開祭壇後恢復組招操作。 |

**畫面判準。** 常用操作先看輪廓辨識，再用明暗、按壓回饋與短標籤補足意思。傳送方向、選取狀態與可確認狀態在白天、夜間都要看得清楚。元素名稱可放在配裝介面；戰鬥中保留中央視野和拇指活動空間。

**傳送門的 3D 光影。** 門面位於石框後方，光屑從門前盤旋進入漩渦，冷色局部光照到門柱和腳邊鋪面。啟動瞬間讓光紋與地面光照一起變化，再切換地點。用連續遊戲畫面核對前後遮擋、光影變化，以及傳送前後的節奏。

**參考依據。** 《元素世界》官方說明提供雙搖桿與組合元素的操作參考。鎖鏈圖案、祭壇換裝及本專案四格出戰規則以 Harvey 的指示為準；手機素材的勘查結果記在交接文件。[官方遊戲頁](https://play.google.com/store/apps/details?id=julyhot.elementalworld)

**驗收。** 從村莊正常出生，用角色移動沿石板路走到西村口，確認界牆和門柱都不擋路。以遊戲鏡頭檢查村口、森林祭壇和出戰格提示，可用 `tools/capture.sh --altar-preview --tag=altar_row` 拍攝土祭壇。實際操作水→火→輕點鎖鏈，確認蒸氣只占一格，無有效配方時保留佇列。沿傳送門往返並替換土、奧術，驗證跨祭壇時舊點按取消、換裝保留佇列、回村後四個出戰鍵和配裝一致。觸控事件回歸與手機實際手感分開記錄。
